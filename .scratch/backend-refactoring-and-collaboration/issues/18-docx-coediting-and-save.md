# 18: Совместное редактирование DOCX и достоверное автосохранение

Status: ready-for-agent

Опубликована после поручения владельца реализовать план 7 ноября 2026 года. Зависимости сохраняются до подтверждённого завершения блокеров.

**What to build:** Два редактора изменяют настоящий DOCX, видят курсоры и общий результат, а сохранённый черновик открывается повторно без создания версии на каждый ввод.

**Blocked by:** [17: Права документа и разделение черновика с опубликованной версией](17-document-grants-and-working-context.md)

**Источник:** [спецификация](../spec.md); истории US-051, US-054, US-055, US-056, US-057, US-058, US-059, US-060, US-061, US-062, US-063; ID-05, ID-08, ID-15, ID-16, ID-18, ID-25, ID-26, ID-36, ID-37, ID-38, ID-41; TD-01, TD-06, TD-09, TD-12, TD-13. US — номер истории в User Stories.

## Критерии приёмки

- [ ] Разрешённый режим редактора открывает Version File/Working Draft, а не Extracted Text; read/comment не превращаются в edit.
- [ ] Два браузерных контекста видят изменения и имена с курсорами; после закрытия и повторного открытия сохранены текст и поддерживаемая структура DOCX.
- [ ] Автосохранение обновляет общий черновик без публикации; UI отдельно показывает соединение, сохранение, выпуск и обработку.
- [ ] EditorAdapter и сценарии Collaboration изолируют протокол; callback аутентифицирован, связан с сессией/поколением и не принимает произвольный URL для скачивания.
- [ ] Повторный/поздний callback и прежнее поколение не подменяют новый черновик; при разрыве до подтверждения нет ложного «Сохранено».
- [ ] Реальные браузеры и закреплённый редактор проходят основной путь; API отдельно проверяет callback, размер/источник файла, отказ зависимости и возобновление актуального состояния.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
