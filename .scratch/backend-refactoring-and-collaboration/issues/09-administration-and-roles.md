## Критерии приёмки

- [x] Администратор управляет пользователями, ролями и блокировкой; обычный сотрудник не вызывает эти операции напрямую.
- [x] Конкурентные блокировки или понижения не устраняют последнего активного администратора; проверка актуального состояния выполняется транзакционно.
- [x] Изменение роли влияет на последующие HTTP-запросы, включая ограничение наблюдателя; блокировка лишает действующей серверной сессии.
- [x] Существенное действие попадает в аудит без секретов; API и UI показывают объяснимый конфликт/отказ.
- [ ] Проверены матрица ролей и гонка последнего администратора. Закрытие уже открытых редакторских каналов реализуется задачей 30.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).

Пока нет обсуждения.


8 ноября 2026 года: реализованы политика User и отдельные действия создания/изменения пользователей. PostgreSQL advisory lock сериализует административные изменения; действующий администратор и целевой пользователь повторно читаются под блокировкой. UI меняет роли и блокирует пользователей; проверяется актуальная сессия. Аудит содержит только изменения роли и активности.

Проверки: HTTP feature test — 1 тест, 8 assertions; существующий DocumentAccessTest — 8 тестов, 30 assertions. Реальная изолированная PostgreSQL с двумя независимыми клиентами: одновременная блокировка двух администраторов вернула 200 и 409, остался один активный администратор. Блокировка сотрудника прекратила доступ обеих ранее открытых сессий (401 и 401). PHPStan, Pint, frontend typecheck и ESLint прошли. Полная ролевая матрица и браузерный сценарий ещё не выполнены; критерий оставлен открытым по просьбе владельца уделять больше времени реализации.

8 ноября 2026: добавлена и запущена HTTP-проверка ролей admin/employee/observer для списка, создания и изменения пользователей: только администратор имеет доступ; вместе с существующей проверкой смены роли — 2 теста, 17 assertions на SQLite в изолированном контейнере. Полная матрица доступа к документам и браузерная проверка не подтверждены; блокер 08 остаётся открытым, задача не закрыта.
