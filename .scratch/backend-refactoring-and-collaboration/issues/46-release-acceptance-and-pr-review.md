## Критерии приёмки

- [ ] На одном commit запущен ранее созданный контур: регистрация→загрузка→поиск→DOCX/XLSX/PPTX→живые обсуждения→публикация→read-only; не создаётся новая архитектура тестов в этой задаче.
- [ ] Пройдены критические отрицательные сценарии: admin non-owner, 10/11 и вкладки, отзыв открытого доступа, неподтверждённое сохранение, позднее задание, статичные обсуждения и повторы передачи.
- [ ] Подтверждены пользовательские регрессии, включая видимость собственного комментария и сохранение позиции чтения; отчёт различает API, реальную инфраструктуру, браузер, моки и ручные проверки.
- [ ] Работа оформлена настоящими PR по gitflow проекта, замечания разобраны; сохранены ссылки на выполненные CI, образы, deploy/smoke и фактическое независимое review.
- [ ] Создание PR, собственный комментарий агента и локальное ревью не подменяют человеческое/независимое одобрение; при отсутствии reviewer этот критерий остаётся открытым.
- [ ] Итоговая матрица связывает все 126 историй, решения и проверки с результатами, перечисляет незакрытые ограничения и не объявляет будущие испытания пройденными.
