# 10: Приватная загрузка с карантином и антивирусом

Status: ready-for-agent

Опубликована после поручения владельца реализовать план 7 ноября 2026 года. Зависимости сохраняются до подтверждённого завершения блокеров.

**What to build:** Подтверждённый сотрудник безопасно загружает поддерживаемый файл, видит этап проверки и причину отказа, не создавая дублей при повторе.

**Blocked by:** [01: Перенести текущую авторизацию документов в Policies](01-document-policies.md); [07: Саморегистрация сотрудника и подтверждение email](07-registration-and-verification.md)

**Источник:** [спецификация](../spec.md); истории US-014, US-017, US-018, US-019, US-020, US-021, US-023; ID-05, ID-08, ID-10, ID-13, ID-15, ID-17, ID-25, ID-38, ID-39, ID-46, ID-47; TD-02, TD-05, TD-07, TD-16, TD-17. US — номер истории в User Stories.

## Критерии приёмки

- [ ] Проверяются размер, фактический тип и повреждение поддерживаемых Office/PDF/изображений/TXT/MD/CSV; отказ понятен пользователю.
- [ ] Создаются приватный документ владельца и кандидат первой версии в закрытом хранении; карантинный/заражённый файл не доступен через download, preview или редактор.
- [ ] Реальный ClamAV и отказ сканера проверены; недоступность зависимости не превращается в успешную проверку. UI различает очередь, проверку и ошибку.
- [ ] Повтор того же ключа и файла возвращает тот же результат; тот же ключ с другими данными отклоняется, лишний файл/версия не остаётся.
- [ ] Приём файла в Documents имеет типизированный вход без HTTP UploadedFile в бизнес-контракте, пригодный для облачного импорта; проверка и антивирус принадлежат Processing.
- [ ] Путь до карантина и результата сканирования проверен API и UI. До готовности дальнейшей обработки файл не объявляется опубликованным; первый готовый выпуск завершает задача 11.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
