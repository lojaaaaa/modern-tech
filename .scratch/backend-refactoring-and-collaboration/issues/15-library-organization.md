# 15: Личная библиотека: папки, теги, избранное и страницы

Status: ready-for-agent

Опубликована после поручения владельца реализовать план 7 ноября 2026 года. Зависимости сохраняются до подтверждённого завершения блокеров.

**What to build:** Пользователь организует доступные документы и возвращается к ним через библиотеку с фильтрами и предсказуемой пагинацией.

**Blocked by:** [11: Первый выпуск с OCR, извлечением текста и индексацией](11-first-publication-processing.md)

**Источник:** [спецификация](../spec.md); истории US-013, US-024, US-025, US-026; ID-02, ID-05, ID-06, ID-12, ID-13, ID-39, ID-46; TD-02, TD-05, TD-16. US — номер истории в User Stories.

## Критерии приёмки

- [ ] Работают папки и теги документов, личное избранное, фильтры, сортировка и страницы; сохранены применимые пакетные операции с проверкой каждого документа. Право чтения не даёт права менять метаданные.
- [ ] Избранное одного пользователя не меняет состояние другого; скрытые документы не раскрываются через названия папок, результаты или счётчики.
- [ ] Условия видимости применяются до итогового count и пагинации; повторяющиеся ключи сортировки дают стабильную выдачу.
- [ ] Операции организации выражены отдельными сценариями, выборка — Query; UI сохраняет корректный выбранный фильтр после изменения.
- [ ] API и браузер проверяют библиотеку двух пользователей, пустые страницы и сочетание фильтров без утечек.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
