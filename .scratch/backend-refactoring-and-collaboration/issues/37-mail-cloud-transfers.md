# 37: Импорт и экспорт через Облако Mail.ru по общему контракту

Status: ready-for-agent

Опубликована после поручения владельца реализовать план 7 ноября 2026 года. Зависимости сохраняются до подтверждённого завершения блокеров.

**What to build:** Пользователь выполняет те же безопасные ручные передачи через второй сохранённый провайдер без другой модели прав и версий.

**Blocked by:** [35: Ручной импорт с Яндекс Диска в приватный документ](35-yandex-cloud-import.md); [36: Экспорт выбранной версии на Яндекс Диск с проверкой прав worker](36-yandex-fixed-version-export.md)

**Источник:** [спецификация](../spec.md); истории US-109, US-110, US-111; ID-02, ID-05, ID-06, ID-08, ID-12, ID-13, ID-24, ID-39, ID-46, ID-47; TD-02, TD-05, TD-15, TD-16. US — номер истории в User Stories.

## Критерии приёмки

- [ ] Подключение Mail.ru поддерживает выбор/импорт файла и экспорт фиксированной готовой версии через общие сценарии Integrations.
- [ ] Провайдерский адаптер изолирует особенности API/авторизации; нет второй копии правил создания документа, карантина или проверки export.
- [ ] Сохранены приватность подключения, общий конвейер импорта и проверка актуальных прав перед экспортом.
- [ ] Повторы/ошибки не приводят к незаметной перезаписи; UI показывает те же согласованные состояния передачи.
- [ ] Общие контрактные тесты проходят для обоих провайдеров; реальный round-trip и ограничения конкретного сервиса фиксируются отдельно при доступных credentials.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
