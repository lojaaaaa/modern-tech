# 02: Прототип: совместно изменить и повторно открыть DOCX, XLSX и PPTX

Status: ready-for-agent

Опубликована после поручения владельца реализовать план 7 ноября 2026 года. Зависимости сохраняются до подтверждённого завершения блокеров.

**What to build:** В изолированном ARM64-стенде два участника изменяют настоящий Office-файл, видят имена и курсоры, сохраняют его и проверяют результат повторным открытием.

**Blocked by:** Нет — можно начинать сразу после согласования плана.

**Источник:** [спецификация](../spec.md); истории US-051, US-052, US-053, US-054, US-055, US-056, US-057, US-125; ID-25, ID-26, ID-43, ID-44; TD-01, TD-09, TD-12, TD-18. US — номер истории в User Stories.

## Критерии приёмки

- [x] Закреплены версия и бесплатная редакция кандидата; первый проверяемый кандидат — ONLYOFFICE Community, альтернатива — Collabora CODE. Платный Automation API не используется как скрытая предпосылка.
- [ ] Для каждого из трёх форматов два независимых клиента видят изменения и курсоры без обновления страницы; результат сходится.
- [ ] После сохранения, закрытия и повторного открытия проверены текст и структура DOCX, значения и формулы XLSX, порядок и содержимое слайдов PPTX.
- [x] Составлен воспроизводимый корпус с оформлением и ограничениями совместимости; несовместимость не объявляется устранённой.
- [ ] Стенд изолирован от рабочей БД и файлов; записаны команды запуска, версия образов, входные файлы и фактические результаты по каждому формату.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
