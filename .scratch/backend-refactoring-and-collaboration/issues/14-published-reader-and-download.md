# 14: Просмотр, история и скачивание опубликованной версии

Status: ready-for-agent

Опубликована после поручения владельца реализовать план 7 ноября 2026 года. Зависимости сохраняются до подтверждённого завершения блокеров.

**What to build:** Читатель выбирает готовую версию, различает исходный файл и извлечённый текст, смотрит preview и скачивает файл при наличии export.

**Blocked by:** [11: Первый выпуск с OCR, извлечением текста и индексацией](11-first-publication-processing.md)

**Источник:** [спецификация](../spec.md); истории US-032, US-033, US-034, US-036, US-037; ID-06, ID-12, ID-13, ID-15, ID-24, ID-25, ID-37, ID-46; TD-05, TD-07, TD-16. US — номер истории в User Stories.

## Критерии приёмки

- [ ] Карточка и история показывают только разрешённые опубликованные версии; выбранная версия явно обозначена, черновик не подменяет историю.
- [ ] Оригинал, preview и извлечённый текст различимы; реальный Gotenberg/поддерживаемые локальные просмотрщики дают производные результаты нужной версии.
- [ ] Чтение само по себе не разрешает download: нужен export; угаданный идентификатор чужой версии/preview не раскрывает содержимое.
- [ ] Ошибки и неготовый preview показываются без небезопасного оригинала или публичной ссылки хранения.
- [ ] API и браузер проверяют выбор версии, контрольную сумму скачанного файла, отказ без export и сохранённые сценарии preview.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
