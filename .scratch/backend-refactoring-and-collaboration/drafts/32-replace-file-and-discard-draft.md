## Критерии приёмки

- [ ] Активное редактирование блокирует замену; наличие неопубликованных изменений также блокирует её независимо от наличия соединений.
- [ ] Владелец может сначала опубликовать черновик либо явно отказаться от него; отказ не снимает запрет при активных редакторах.
- [ ] UI показывает причину и последствия отказа; сервер повторно проверяет актуальное состояние в гонке с новым подключением/изменением.
- [ ] После разрешённой замены новый файл проходит безопасный приём и обычные правила публикации владельцем, сохраняя прошлые неизменяемые версии.
- [ ] Поколение и сессии сменены согласованно; старое сохранение или событие не восстанавливает отброшенную работу. Отказ/замена идемпотентны и аудируются.
- [ ] API и браузер проверяют грязный/чистый черновик, активное/освободившееся место и конкурирующий вход редактора.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
