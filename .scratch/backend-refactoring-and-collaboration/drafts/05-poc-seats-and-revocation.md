**What to build:** Проверено, что бесплатный редактор позволяет реализовать лимит людей и прекращать передачу данных уже подключённому участнику.

## Критерии приёмки

- [ ] Десять разных аккаунтов допускаются к редактированию; одиннадцатый получает разрешённый просмотр/комментирование и возможность повторной попытки без вытеснения действующего редактора.
- [ ] Две вкладки одного аккаунта занимают одно место; закрытие одной вкладки сохраняет место оставшейся. Проверены разрыв связи, переподключение и освобождение завершённых сессий.
- [ ] Одновременные попытки занять последнее место проверены с реальным Redis/БД, без отдельного незащищённого count-then-insert.
- [ ] Для открытых вкладок проверены отзыв edit с сохранением comment, потеря всех прав черновика при оставшемся read, отзыв read и блокировка аккаунта.
- [ ] Зафиксированы механизм остановки редактора и подписок, фактические задержки и ограничения отзыва; скрытие элементов UI не считается доказательством.
- [ ] Есть воспроизводимый протокол и результаты 10/11 аккаунтов и нескольких вкладок на целевом стенде.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
