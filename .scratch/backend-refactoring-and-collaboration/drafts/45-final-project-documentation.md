## Критерии приёмки

- [ ] README воспроизводит запуск/демонстрацию; схема показывает пять бизнес-модулей, адаптеры и общую инфраструктуру с очередями и внешними интеграциями.
- [ ] OpenAPI и генерируемые клиентские типы соответствуют реальным операциям, контекстам, состояниям и ошибкам; drift проверяется автоматически.
- [ ] Исходник ТЗ в Markdown актуализирован; итоговый проверенный PDF содержит 25–30 страниц без искусственного наполнения и описывает согласованный объём.
- [ ] В документах явно указаны owner-only публикация, 10 людей на документ, email-подтверждение, черновик/история, статичные комментарии и измеренный общий бюджет.
- [ ] Ограничения OCR/NER/редактора/провайдеров и доступность внешних проверок описаны честно; требования связаны с фактами реализации и приёмки.
- [ ] Есть схема данных/потоков, правила backup/rollback, эксплуатационные инструкции и ссылки на доказательства. Каноническая спецификация не дублируется новым конкурирующим текстом.
