# 01: Перенести текущую авторизацию документов в Policies

Status: needs-triage

Черновик для согласования. Публикация в `issues/` и статус `ready-for-agent` — после утверждения разбиения.

**What to build:** Текущие операции с документом продолжают работать с едиными проверками доступа; существующие ограничения выдачи и приватность сохраняются при устранении отдельной обёртки Access.

**Blocked by:** Нет — можно начинать сразу после согласования плана.

**Источник:** [спецификация](../spec.md); истории US-015, US-016, US-031, US-037, US-049, US-114, US-115; ID-02, ID-04, ID-06, ID-07, ID-13; TD-02, TD-03, TD-05, TD-16. US — номер истории в User Stories.

## Критерии приёмки

- [ ] Проверки одного документа используют Policies владельца сущности; SQL-ограничение видимости остаётся частью Query и применяется до count, пагинации и фрагментов.
- [ ] Матрица действующих ролей проходит для карточки, preview, скачивания и вложенных ресурсов; идентификатор чужой версии не подменяет проверку принадлежности.
- [ ] Удалена заменённая обёртка Access после переноса всех её потребителей; нет универсального Service/Action для всех действий.
- [ ] Сохранены текущие пользовательские результаты и API-проверки приватности; новые правила публикации будут введены отдельно, без административного обхода.
- [ ] Изменение проходит имеющиеся проверки в отдельном PR; не требует сброса рабочей БД или одновременного переписывания остальных модулей.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
