# 42: Воспроизводимый запуск всей платформы на ARM64 через Compose

Status: needs-triage

Черновик для согласования. Публикация в `issues/` и статус `ready-for-agent` — после утверждения разбиения.

**What to build:** После подготовки образов и ресурсов владелец запускает локальную платформу без обязательного платного API и демонстрирует основной контур без интернета.

**Blocked by:** [41: Диагностика редактора, обработки и очередей: логи, метрики, readiness](41-runtime-observability.md)

**Источник:** [спецификация](../spec.md); истории US-117; ID-01, ID-10, ID-25, ID-43, ID-45, ID-48, ID-50; TD-01, TD-07, TD-09, TD-15, TD-18. US — номер истории в User Stories.

## Критерии приёмки

- [ ] Закреплены совместимые образы/версии приложения, PostgreSQL, отдельных Redis очереди/кэша, обработчиков, редактора и realtime; есть healthcheck и порядок готовности.
- [ ] Чистый изолированный ARM64-стенд поднимается по инструкции, получает подготовленные тестовые аккаунты/корпус и проходит загрузку, поиск, coedit и комментарий.
- [ ] После заранее выполненных загрузки образов, шрифтов/языковых ресурсов основной локальный контур проверен без интернета; облака и реальная почта явно требуют свою сеть/настройку.
- [ ] Секреты и тома не попадают в образ/репозиторий; рестарт сохраняет опубликованные файлы, подтверждённый черновик и обсуждения.
- [ ] Конфигурация учитывает измеренный общий бюджет, не заменяет лимит 10 людей лимитом вкладок и не использует неподтверждённый платный мост.
- [ ] Не выполняется неоговорённый reset действующей БД; ограничения машины и проверенный профиль запуска записаны.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
