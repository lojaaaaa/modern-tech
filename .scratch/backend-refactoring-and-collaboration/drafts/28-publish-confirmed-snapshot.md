Status: needs-triage

Черновик для согласования. Публикация в `issues/` и статус `ready-for-agent` — после утверждения разбиения.

**What to build:** Владелец публикует согласованный снимок, а читатель получает неизменяемый файл и обсуждения одного выпуска.

US — номер истории в User Stories.

## Критерии приёмки

- [ ] Инициировать выпуск может только действующий владелец; администратор чужого документа также получает отказ. Автосохранение/callback/закрытие не публикуют.
- [ ] Через доказанный контракт получен Confirmed Snapshot файла и обсуждений одного поколения; нет подтверждения — понятный отказ и безопасный повтор, без требования смыслового одобрения всех участников.
- [ ] После получения снимка короткая транзакция повторно проверяет владельца, поколение и идемпотентность и фиксирует кандидат, историю, audit и outbox.
- [ ] Файл и ветки готового выпуска неизменяемы; рабочее редактирование/удаление после захвата не меняет историю и остаётся неопубликованным.
- [ ] До готовности нового выпуска read-only продолжает видеть предыдущий; рабочие комментарии не приходят в его подписку. UI различает принятие запроса, обработку и публикацию.
- [ ] Браузерный сценарий для владельца, редактора, read-only и администратора подтверждает файл+обсуждения; API проверяет принадлежность ресурсов и повтор ключа.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
