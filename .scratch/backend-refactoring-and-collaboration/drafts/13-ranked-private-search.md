# 13: Полнотекстовый поиск опубликованных документов с ранжированием

Status: needs-triage

Черновик для согласования. Публикация в `issues/` и статус `ready-for-agent` — после утверждения разбиения.

**What to build:** Пользователь ищет русские и английские документы, получает релевантные фрагменты и корректные счётчики в пределах своего доступа.

**Blocked by:** [11: Первый выпуск с OCR, извлечением текста и индексацией](11-first-publication-processing.md)

**Источник:** [спецификация](../spec.md); истории US-028, US-029, US-030, US-031, US-124; ID-04, ID-06, ID-12, ID-13, ID-22, ID-37, ID-39, ID-46; TD-05, TD-07, TD-16. US — номер истории в User Stories.

## Критерии приёмки

- [ ] Реальный PostgreSQL проверяет RU/EN-морфологию, ранжирование, фрагменты и работу GIN-индекса на различимом корпусе.
- [ ] Поиск использует опубликованную версию; черновик и обрабатываемый кандидат не раскрываются через текст, snippet, count, сортировку или страницы.
- [ ] Права накладываются до count/пагинации; отозванный доступ и смена аккаунта не возвращают результаты из кэша.
- [ ] Выдача и фильтры остаются Query-сценарием Documents, не превращаются в универсальный Action; UI обрабатывает пустую выдачу, ошибки и смену запроса.
- [ ] В негативных HTTP-проверках есть посторонний пользователь, наблюдатель, администратор и чужая версия; SQLite не подменяет доказательство FTS.

Применяются [общие условия приёмки плана](../ticket-plan.md#общие-условия-приёмки).
