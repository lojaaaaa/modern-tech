# ADR-001: baseline архитектуры

Статус: принято как инженерное решение по поручению владельца, 2026-10-31.

## Решение и альтернативы

1. Модульный Laravel вместо набора бизнес-микросервисов. Единые транзакции ACL/версий/аудита и один release уменьшают риск согласованности. Отдельные OCR/preview/NLP-процессы изолируют нагрузку. Пересмотр: независимые команды или доказанная потребность в отдельных release/scale.
2. PostgreSQL FTS вместо OpenSearch. ACL и поиск читаются согласованно; не нужен протокол синхронизации прав в отдельном индексе. Цена: chunking, настройка ранжирования, ограниченная семантика фраз на границах. Пересмотр: контрольный корпус/нагрузка не проходят после разумной оптимизации.
3. Приватный volume вместо обязательного S3. Бесплатная локальная работа и простое восстановление; цена - привязка к локальному диску. Storage adapter сохраняет путь миграции. Пересмотр: удалённый постоянный хостинг.
4. Sanctum session вместо браузерного JWT. Same-origin, серверный отзыв и CSRF; облачный OAuth остаётся отдельным механизмом подключения. Credentials только серверные.
5. Transactional outbox и идемпотентные этапы вместо надежды на exactly-once. Дополнительные таблицы/dispatcher окупаются проверяемым восстановлением после сбоя.
6. FSD app/pages/features/shared, Query для server state и Zustand для UI. Shared не содержит доменные сущности ради удобства импорта. Новые слои вводятся только при обосновании.
7. Scramble → OpenAPI → openapi-typescript. До endpoint контракт согласуется; после реализации экспорт сверяется тестами. Ручные независимые копии DTO запрещены.
8. Локальный deploy обязателен, Render опционален. Бесплатный Render не эквивалентен Compose с persistent files/workers. Пересмотр отдельным ADR при решении о публикации.

## Проверки до зависимой реализации

ARM64 manifest/память, совместимость Laravel/PHP/Scramble, смешанный PDF, NER качество, OAuth redirect и WebDAV safe-create. Сбой проверки блокирует зависимые задачи, а не позволяет молча убрать интеграцию. Версии закрепляются lockfiles и digest после проверки. Подробные источники - RESEARCH.md.
