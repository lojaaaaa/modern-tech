Граф dependencies в JSON точнее линейного порядка: часть UI/интеграций может выполняться после своих зависимостей без ожидания всех номеров предыдущего этапа. Работа агента - одна задача за сессию. Параллельные агенты этой документацией не назначаются.

## Release gates

- Все FR/NFR проверены по TEST_PLAN; critical failures отсутствуют.
- Реальные cloud round-trip не заменены mocks; credentials не опубликованы.
- Полный offline core и ARM64 запуск воспроизводимы.
- Backup/restore и deploy/rollback выполнены, а не только описаны.
- Есть PR review evidence; если нет reviewer/remote, это явный незакрытый gate.
- README/OpenAPI соответствуют работающей реализации; скриншоты и отчёт доступны.

При неуспехе измеримого требования заводится change record с влиянием. Опциональный Render не блокирует локальную сдачу. Недостаток RAM решается измерением/ограничением concurrency и документированием профиля, а не отключением безопасности.
