# Аудит продукта, 31 октября 2026

Исправлены: лимит 12 документов, сохранение фильтров при пагинации, серверная фильтрация формата/статуса/дат, сортировки, вписывание картинки по высоте, компактный заголовок, размер кнопки подключения, скрытие пустых передач и русские названия событий.

## Открытые проблемы

- P1: журнал аудита требует переключателя страниц и фильтра событий; API уже отдаёт 12 строк и имена.
- P1: комментарии требуют серверной идемпотентности.
- P1: preview требует постоянных состояний и восстановления зависших конвертаций.
- P1: приглашения, восстановление пароля в UI, live cloud round-trip ещё не завершены.
- P2: выдача доступа по ID неудобна — нужен поиск участников.
- P2: PDF зависит от браузерного viewer; нет общих закладок/аннотаций.
- P2: накопленные CSS overrides нужно разнести по страницам и заменить единым grid shell.
- P2: визуальная проверка 1920×1080/1440×900/768×1024/390×844 не подтверждена: browser automation отключён в Work settings.

## Идеи

1. Сохранённые представления и запросы с фильтрами в URL.
2. Сравнение версий текста с подсветкой изменений.
3. Дубликаты по SHA-256 с предложением новой версии.
4. Массовые действия: теги, папки, экспорт.
5. Панель этапов обработки с понятными ошибками и безопасным повтором.
6. Inbox сущностей для ручного подтверждения дат/сумм/организаций.
7. Command palette и горячие клавиши.
8. Объяснение доступа: кто видит файл и почему.
9. Полноэкранный reader, миниатюры страниц, закладки.
10. Навигация по комментариям и фильтр незакрытых обсуждений.
11. Центр хранения с объёмами и датой backup.
12. Локальные уведомления по сохранённым поискам.

Основания: скриншоты владельца, чтение UI/API и тестов. Reflow: https://www.w3.org/WAI/WCAG21/Understanding/reflow ; таблицы: https://github.com/carbon-design-system/carbon/blob/main/packages/react/src/components/DataTable/DataTable.mdx . Идеи — предложения, не реализованные возможности.

## Принято владельцем

Идеи 1–5, 7, 9–12 одобрены для дальнейшей реализации. Идеи 6 (Inbox сущностей) и 8 (объяснение доступа) исключены из этого расширения. Это не удаляет базовые требования ТЗ к ACL/NER. Полное закрытие списка выше ещё не выполнено.

## Дополнение интерфейса

Форма контекстного комментария перенесена непосредственно к выделению текста. Фильтры дат библиотеки/корзины свёрнуты в popover, сброс заменён крестиком; основные фильтры занимают одну строку на desktop. Заголовок документа и отступы дополнительно сокращены.
