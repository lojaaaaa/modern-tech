## Кандидат и воспроизведение

ONLYOFFICE Docs **Community9.4.0.1**, бесплатный self-hosted образ,
`platform: linux/arm64`. Compose закрепляет multiarch digest:

```text
onlyoffice/documentserver:9.4.0.1@sha256:3ab6ebc7c605e5a32b7ae3ff19daed4925090245acc8100ce2230bd766c88212
ARM64 manifest: sha256:4cf3b55487209b8f53492c545263b7bb257e1be48dba1f9e0b30d2e50371a1c8
```

Команды запуска, проверки, остановки и полный протокол двух клиентов находятся
в [tools/office-poc/README.md](../../tools/office-poc/README.md). Compose содержит
только отдельные harness/documentserver; рабочие PostgreSQL/Redis/файлы не
монтируются. Docker project: `modern-tech-office-poc`, loopback8890/8891.

Среда: macOS ARM64, Docker Engine28.5.1 aarch64,8CPU,7.65GiB Docker memory;
Node24.18.0 на хосте, CPython3.14.7, zlib1.2.12. Существующая платформа продолжает
работать отдельно; её БД и файлы не сбрасывались.

HTTP-тесты выполнялись Node test runner в отдельном контейнере `--network none`:
2tests,2pass. Первый тест показал red на отсутствующем HTTP-стенде, затем green.
Они проверяют сервис прототипа, **не совместное редактирование**. Browser-probe
сохраняет машинный отчёт в игнорируемый `tools/office-poc/data/browser/readiness.json`.

На момент измерения загрузка больших слоёв DockerHub оставалась медленной:

оно ничего не доказывает о работоспособности либо непригодности редактора.

## Корпус и незавершённая приёмка

| Файл | Размер | SHA256 исходного файла |
|---|---:|---|
| sample.docx |37032 | `a42632c1ff623390665e7fcabeedc4d675e73bff10559b792950a97b6f1afd11` |
| sample.xlsx |5706 | `a69d1f282c31850d2b8ebf6146b0225ecd2c1d3f83cbf6d97be969600cb34856` |
| sample.pptx |29231 | `5069565e0f75975f99f89204475c8aef1c73783677ed4a3c729ce48e47a92a46` |

| Формат | Генерация/независимое чтение |2клиента, изменения и курсоры | Сохранение/закрытие/открытие |
|---|---|---|---|
| DOCX | Проходит: текст, таблица, жирный фрагмент | Не выполнено: образ не загружен | Не выполнено |
| XLSX | Проходит: листы, значения, формулы, форматирование | Не выполнено: образ не загружен | Не выполнено; вычисленный кэш появится после редактора |
| PPTX | Проходит: два слайда, порядок, Unicode | Не выполнено: образ не загружен | Не выполнено |

Ограничения корпуса: нет макросов, SmartArt, диаграмм, вложенных объектов и
исчерпывающего покрытия сложной вёрстки/шрифтов. Совместимость с Microsoft Office
в целом этим корпусом не доказана. Файлы, полученные от редактора, пока отсутствуют.
`verify --edited` требует оба маркера DOCX/PPTX,17/25 и формулу/результат42 в XLSX,
таблицу/форматирование/порядок; оригиналы не проходят за изменённые артефакты.

Для завершения02 требуется дождаться загрузки закреплённого образа, выполнить
протокол с двумя независимыми клиентами для каждого формата, сохранить screenshots
с курсорами/именами и файлы callback, закрыть клиентов, повторно открыть сохранённые
файлы и запустить независимую проверку. Только после фактического прохождения
можно снять блокер03/05. Нужные команды уже находятся в README стенда.
