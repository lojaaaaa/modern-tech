# Issue tracker: Local Markdown

- Feature directory: .scratch/<feature-slug>/
- Specification: .scratch/<feature-slug>/spec.md
- Tickets: .scratch/<feature-slug>/issues/<NN>-<slug>.md
- Number tickets from 01, one ticket per file.
- Record triage state near the top as Status: <label>.
- Use the vocabulary in triage-labels.md.
- Append conversation under a Comments heading.
- Publishing means creating or updating the corresponding local file.
- Read existing feature files before publishing to avoid duplicates.
- Keep one authoritative specification; other documents link to it.
